# Informações do Sistema Linux

## uname
Mostra informações do kernel e do sistema.

```bash
uname -a
```

## whoami
Mostra o nome do usuário atual.

```bash
whoami
```

## date
Mostra a data e o horário.

```bash
date
```

## df
Mostra o espaço utilizado e disponível nos sistemas de arquivos.

```bash
df -h
```

## free
Mostra informações sobre o uso da memória.

```bash
free -h
```

## top
Exibe processos e consumo de recursos em tempo real. Para sair, pressione `q`.

```bash
top
```

## uptime
Mostra há quanto tempo o sistema está ligado.

```bash
uptime
```
