# Manipulação de Arquivos no Linux

## mkdir
Cria um diretório.

```bash
mkdir projetos
```

## touch
Cria um arquivo vazio.

```bash
touch exemplo.txt
```

## cp
Copia um arquivo.

```bash
cp exemplo.txt copia.txt
```

## mv
Move ou renomeia um arquivo.

```bash
mv exemplo.txt novo-nome.txt
```

## rm
Remove um arquivo. Use com atenção, pois a remoção normalmente não vai para a lixeira.

```bash
rm exemplo.txt
```

## cat
Mostra o conteúdo de um arquivo de texto.

```bash
cat exemplo.txt
```

## nano
Abre um arquivo no editor de texto do terminal.

```bash
nano exemplo.txt
```
