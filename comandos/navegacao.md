# Comandos de Navegação Linux

## pwd
Mostra o caminho do diretório atual.

```bash
pwd
```

## ls
Lista arquivos e pastas do diretório atual.

```bash
ls
ls -la
```

## cd
Entra em um diretório.

```bash
cd Documentos
```

## cd ..
Volta um nível na estrutura de diretórios.

```bash
cd ..
```

## cd ~
Vai para a pasta pessoal do usuário.

```bash
cd ~
```

## clear
Limpa a tela do terminal.

```bash
clear
```
