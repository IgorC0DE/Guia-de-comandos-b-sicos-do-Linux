# Exercícios Práticos - Linux

Tente responder e executar os exercícios no terminal.

## Questões

1. Qual comando mostra o diretório atual?
2. Qual comando lista arquivos e pastas?
3. Como criar uma pasta chamada `estudos`?
4. Qual comando mostra o usuário atual?
5. Como verificar o espaço disponível no disco?
6. Qual comando copia um arquivo?

## Desafio

1. Crie uma pasta chamada `teste`.
2. Entre nessa pasta.
3. Crie um arquivo chamado `atividade.txt`.
4. Use `ls` para confirmar que o arquivo foi criado.
5. Volte para o diretório anterior e remova a pasta de teste.

Comandos que podem ajudar:

```bash
mkdir teste
cd teste
touch atividade.txt
ls
cd ..
rm -r teste
```

**Atenção:** o comando `rm -r` remove a pasta e seu conteúdo. Confira o caminho antes de executá-lo.
