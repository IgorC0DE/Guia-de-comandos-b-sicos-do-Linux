# Guia de Comandos Básicos do Linux

Projeto de estudo criado para reunir comandos básicos do terminal Linux, com explicações e exemplos práticos.

## Conteúdos

- [Navegação entre diretórios](comandos/navegacao.md)
- [Manipulação de arquivos](comandos/arquivos.md)

- Terminal
- Markdown
- Git e GitHub
